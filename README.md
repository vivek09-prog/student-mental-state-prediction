This project is a Machine Learning-based Student Mental State Prediction system that predicts a student’s final state (Relaxed, Neutral, or Stress) using behavioral, emotional, and academic features. The dataset was preprocessed using Ordinal Encoding for ordered categorical features such as Stress Level, Anxiety Level, and Academic Year, One Hot Encoding for nominal categorical features like Department, Gender, Facial Emotion, Mood State, and Previous Intervention, and Label Encoding for the target column. A DecisionTreeClassifier and RandomForestClassifier were trained and evaluated, achieving around 75% accuracy. The trained model was then saved using Python Pickle for future deployment and prediction tasks.
